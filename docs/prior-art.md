# Prior art

- **Petari** (SMGCommunity, CC0): the matching decomp; imported as `decomp/`. 99.9% of code matches on RMGE01.
- **Nebula** (keepvaibin, GPL-3.0-only): a native port of Petari's game code with D3D12/Vulkan/D3D11/Metal
  renderers, Windows/Linux/macOS/Android packages, a disc importer, saves (Dolphin/Wii/Switch import), mods (`.luma`),
  frame-rate unlock with interpolation; imported as `port/`. Written largely with Claude, per its README.
- **AstroCore**: SMGCommunity's own work-in-progress PC port, discussed on their Discord; not public.
- **Dolphin**: emulation; the reference for the game's runtime behaviour.
